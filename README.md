# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ株式会社」の企業サイトです。デモとして作成したもので、社名・人物・実績はすべて創作です。

## 概要

`index.html` 1ファイルで構成された静的サイトです。HTML・CSS・JavaScript をすべてこのファイルに収めています。ビルドやサーバーは必要ありません。

### ページ構成

| セクション | 内容 |
| --- | --- |
| お知らせ | 最新ニュース（リリース・移転・採用） |
| ヒーロー | キャッチコピーと、開発プロダクトの月間利用者数をビルの高さで表した立面図 |
| 事業内容 | 受託システム開発／Webサービス・アプリ開発／クラウド基盤・SRE／技術顧問・内製化支援 |
| 開発実績 | プロダクト一覧の表。行にカーソルを合わせると、立面図の対応するビルがハイライトされる |
| 開発の進め方 | 要件定義から運用・保守までの5工程 |
| 会社概要 | 代表メッセージと会社情報 |
| お問い合わせ | 連絡先と問い合わせフォーム（デモのため実際には送信されない） |

### 特徴

- ライトモード・ダークモードに対応（OS の設定に追従）
- スマートフォン幅に対応したレスポンシブレイアウト
- 立面図と実績表は、`index.html` 内の `products` 配列から JavaScript で生成
- フォントは Google Fonts から読み込み（オフライン時は代替フォントで表示）

## ブラウザで開く手順

### 方法1: ファイルを直接開く

1. エクスプローラーで `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

別のブラウザで開くときは、`index.html` を右クリックし、「プログラムから開く」でブラウザを選んでください。ブラウザのウィンドウに `index.html` をドラッグ＆ドロップしても開けます。

### 方法2: コマンドラインから開く

PowerShell で、このフォルダに移動してから次を実行します。

```powershell
Start-Process index.html
```

macOS では `open index.html`、Linux では `xdg-open index.html` を使います。

### 方法3: ローカルサーバーで開く（任意）

`http://` でアクセスして確認したいときは、ローカルサーバーを起動します。Python がインストールされていれば、次のコマンドで起動できます。

```powershell
python -m http.server 8000
```

起動したら、ブラウザで <http://localhost:8000/> を開きます。停止するときは `Ctrl + C` を押します。
